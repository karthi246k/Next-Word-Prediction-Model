# Next-Word-Prediction-Model

### AI & NLP Based Text Prediction System using LSTM

This project is a deep learning-based **Next Word Prediction System** developed using **Natural Language Processing (NLP)** and **LSTM (Long Short-Term Memory)** networks.

The system predicts the most probable next word for a given input phrase and provides the **top 5 predictions with confidence scores** through an interactive web interface.

# Features

## Intelligent Next Word Prediction

* Predicts the next probable word based on input text
* Uses deep learning sequence modeling
* Generates context-aware predictions

---

## NLP Text Processing

* Text cleaning and preprocessing
* Tokenization and vocabulary generation
* N-gram sequence creation
* Padding and sequence preparation

---

## Deep Learning Model

* LSTM-based neural network architecture
* Embedding layer for word relationships
* Dense layer with Softmax activation
* Trained for sequence prediction tasks

---

## Interactive Web Application

* Real-time word prediction
* User-friendly interface
* Dynamic word suggestion system
* Sentence continuation functionality

---

## Top 5 Word Suggestions

* Displays top 5 predicted next words
* Shows probability/confidence score
* Allows users to append predicted words interactively
